1Свайп с отдачей, без стрелок

Полоска целиком следует за пальцем, за пределом ~90px — резиновое сопротивление (демпфирование ×0.35). Если протянул больше 55px — старая неделя улетает в сторону свайпа, новая влетает с обратной стороны и садится на место с лёгким пружинным перелётом. Не дотянул — резинкой возвращается в ноль. Свайп вперёд дальше текущей недели просто не проходит порог (будущего не существует).

2Цвет столбиков — дистанция от цели

diff = |сумма_дня − цель|
diff ≤ 150 → зелёный
diff > 150 → градиент жёлтый→красный (150 = жёлтый, 600+ = красный)
сегодня → всегда белый, формула не применяется

3Новые окна + перекус по калориям, не по времени

Завтрак 04:00–11:59
Обед 12:00–17:59
Ужин 18:00–03:59 (через полночь)

на каждую запись отдельно:
если kcal ≤ 200 → «Перекус» (не важно когда)
иначе → окно по времени как выше

Секции на экране сортируются по времени первой записи в группе — «Перекус» не привязан к фиксированному месту в списке, встаёт туда, где реально случился.
